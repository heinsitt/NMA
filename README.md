# Naing Moe Aung — System Engineer Portfolio

Portfolio of **Naing Moe Aung**, System Engineer transitioning into Cloud Engineering. Built as a high-performance React application using Vite and TypeScript.

## Architecture & Features

- **Framework**: React 18 with TypeScript and Vite
- **3D Network Topology Scene**: Interactive Three.js particle network with proximity links, gentle sine wave drifting motion, mouse parallax, and scroll dolly
- **Interactive Terminal**: Real-time typewriter command execution, syntax highlighting, active uptime counter, and 3D card perspective tilt
- **Topography Design System**: Precision dark ink palette (`#0A0F14`), slate surfaces, teal accents (`#2DD4BF`), and amber pops (`#F59E0B`)
- **Interactive Custom Cursor**: Dual-element trailing ring cursor with hover expansions for interactive elements
- **Scroll Spy & Reveal**: Smooth viewport animations and active navigation section indicators
- **Responsive Mobile Navigation**: Touch-friendly hamburger drawer and optimized layout for all viewport sizes
- **Interactive Contact**: Direct copy-to-clipboard functionality with feedback and LinkedIn integration

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Run TypeScript checks
npm run lint

# Build production bundle
npm run build
```
